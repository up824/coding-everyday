# 写字岛

给小朋友用的练字小游戏：在 iPad 上用 Apple Pencil（或手指）练习写数字 0–9、大写字母 A–Z、小写字母 a–z，
再到多位数和加减乘除算式、常用单词、句子，最后自己写出一小段话。
它是一个纯网页应用，不需要安装，也没有任何依赖。

## 玩法

- **闯关**：六座岛，共 58 关。前三座岛（数字岛、大写字母岛、小写字母岛）每一关学 3 个左右的字符，每个字符走三步：
  1. **描红**：沿着灰色的字帖写，有笔顺号码、方向箭头和示范动画
  2. **虚线**：只剩虚线，自己把握笔画
  3. **自己写**：格子是空的，看着旁边的样子写出来，由程序识别对不对、占格准不准

  每座岛的最后一关是「大挑战」，随机抽字符直接自己写。
- **算术岛**：先写两位数、几百、几千的数，再单独练 + − × ÷ = 这五个符号，然后写整条算式
  （加法、减法、乘法、除法，最后是几百几千的大数算式），共 9 关加一关大挑战。运算符号和数字一样要自己写、要检查；
  算式尽量排在一行里。每条都带中文读法（三加五等于八），点喇叭可以听。
- **单词岛**：65 个常用单词，按主题分成 13 关（你我他、小动物、颜色、好吃的……）。每个单词先描红、再自己写。
- **句子岛**：34 个句子，按单词数从少到多排：两个词（Thank you.）→ 三个词 → …… → 十二个词，
  最后两关是把几句话连起来，自己写出一小段（介绍自己、我的一天）。句子太长时会自动折成几行。

  自己写单词和句子时，每个字母下面有一条小横线，写好后逐个字母检查：对的横线变绿，不对的变红，
  只需要把红色的那几个字母重写。每个单词和句子都带中文意思，点喇叭可以听英文朗读。

  标点符号已经印在格子里，任何时候都不用孩子描或写，也不检查。判定偏宽：字母写得不太标准也算对，
  o 只要是一笔画成、大致合上的圈就行；长一点的句子每 8 个字母允许 1 个没认出来。
- **奖励**：每写完一个字按准确度给 1–3 颗星，一颗星换一颗宝石，还有分数、连击、等级称号、每日目标和成就。
  宝石可以在商店换墨水（彩虹笔、火焰笔……）、写字板（小黑板、星空板）和伙伴。
- **字体**：首页右上角（或设置里）可以换字帖的字体，换了以后字帖、示范、关卡和识别都会跟着换，已有的星星和宝石不受影响。
  - 标准体：端正的印刷体，横平竖直
  - 斜体：写法相同，整体向右倾斜约 10°
  - 手写体：向右倾斜，a d h i l m n t u 收笔带小尾巴，y 写成 u 加钩，接近学校常教的手写体

  用倾斜的字体时，写字板上会多一组淡淡的斜线，帮助把每个字写成一样的斜度。
- **自由练习**：任选一个字符、任选一种方式练。
- **成长记录**：最近 7 天的练习量、每个字／单词／句子练到了哪一步、每个字的准确度变化、需要多练的字（可一键专项练习）。

## 在 iPad 上使用

- 用 Safari 打开页面即可。Apple Pencil 有压感，下笔轻重会改变线条粗细。
- 第一次用笔写之后会自动切换成「只认笔尖」，手掌放在屏幕上不会误触；写字板右上角可以随时切回「手指也能写」。
- 把这个目录放到任意 HTTPS 静态托管（例如 GitHub Pages）后，可以在 Safari 的分享菜单里选「添加到主屏幕」，
  之后像 App 一样全屏打开，并且可以离线使用。
- 设置里可以调：描红判定的宽严、字的大小、左右手、朗读语言（中文 / English）、每日目标。

## 进度保存在哪里

进度保存在浏览器的本地存储里。作为 Claude Artifact 打开时，还会同步到每个人自己的私有云端存档，换设备也能接着练。

## 开发

```
node build.mjs              # 把 src/ 拼成 index.html（独立网页）、dist/artifact.html（Artifact 用）和 iPadOS App 里的页面
node test/engine.test.cjs   # 判定引擎测试：模拟书写，检查描红判定和默写识别
node test/ui.test.cjs       # 界面测试：用模拟笔迹打通第一关并截图（需要 Playwright）
node test/perf.cjs          # 量写字时每次笔尖移动触发了多少次样式重算和排版（越少越跟手）
```

| 文件 | 内容 |
| --- | --- |
| `src/glyphs.js` | 62 个字符、5 个运算符号和 5 个标点的笔画数据（四线三格坐标系，按笔顺和书写方向）、字体表 `STYLES`、把文字排成几行的 `compose` |
| `src/engine.js` | 描红判定（逐笔跟踪进度）和默写识别（点云匹配） |
| `src/words.js` | 单词、句子（英文 + 中文意思）和多位数、算式（读法自动生成） |
| `src/board.js` | 写字板：四线格、字帖、墨迹、Apple Pencil 输入。笔在动的时候只往 canvas 上画，不改 DOM |
| `src/store.js` | 存档、关卡、奖励、商店、成就 |
| `src/audio.js` | 音效（WebAudio 合成）和朗读 |
| `src/app.js`、`src/style.css`、`src/body.html` | 界面 |
| `sw.js`、`manifest.webmanifest`、`icons/` | 离线缓存和主屏幕图标 |
| `ios/` | iPadOS App 工程（把同一张网页包成 App），用法见 `ios/README.md` |

### 加单词、句子和算式

在 `src/words.js` 里照着现有的格式加 `['英文', '中文意思']` 就行，关卡、自由练习和成长记录都会跟着更新。
数和算式加在 `MATH_SRC` 里，只写式子本身（减号用键盘上的 `-`，乘除用 `×` `÷`），读法会自动生成；测试会检查算式算得对不对。
只能用字母、数字、空格和 `. , ? ! '` 这几个标点（标点只印出来，不要求写）。句子多长都可以，写字板会自动折行。

### 加一种新字体

字形都是自己画的笔画数据，不是字体文件（描红需要知道每一笔的顺序和方向，普通字体文件里没有这个信息）。
在 `src/glyphs.js` 的 `STYLES` 里加一项即可：`slant` 是向右倾斜的角度，`over` 里放和标准体写法不同的字符
（没放的沿用标准体）。加完跑一遍 `node test/engine.test.cjs`，它会检查新字体的每个字符都能描红、能被识别。
